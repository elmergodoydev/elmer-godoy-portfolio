# Elmer Godoy Angeles — Portfolio V3

Portfolio profesional de una sola página construido con React + Vite, MUI, Motion y React Three Fiber.

## Requisitos

- Node.js 20 o superior recomendado
- npm

## Levantar en local

```bash
npm install
npm run dev
```

Abre la dirección que muestre Vite, normalmente `http://localhost:5173`.

## Build de producción

```bash
npm run build
npm run preview
```

## Deploy en Vercel

Sube el proyecto a GitHub y luego impórtalo en Vercel. Vercel detecta Vite y ejecuta el build automáticamente.

## Notas de diseño

- Responsive para desktop, tablet y móvil.
- Tema negro con azul eléctrico.
- Glassmorphism selectivo.
- Hero con fotografía profesional y flujo visual de análisis a despliegue.
- Animaciones con Motion.
- Fondo 3D con React Three Fiber.
- Timeline de experiencia.
- Tecnologías con iconos.
- Selector ES/EN en la misma página.
